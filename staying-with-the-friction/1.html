Staying with the Friction

Geist

Nathan Bayliss

A non-human agent wanders within an fractured and impressionistic environment. The agent examines the pieces and attempts to find meaning between them - guiding itself step by step, turning left and right and deciding to flee if it feels uneasy. An external voice coaxes to keep the agent exploring, encourages it to feel more at home within these mysterious locations. The wanderer gets more anxious over time, may attempt to retreat, but it can never escape - it is trapped within this loop.  This work explores the claustrophobic recursion of nostalgia, in this case, a "memoryscape" from archival sources from the artist's life. These locations have been scanned in 3D, some have been drawn from archival photos, and hallucinated into spatial environments. These are places of meaning and memory for the artist, but unknown to the agent that traverses between them.  Variable duration - Created in p5.js, Custom LLM, binaural field recording, generative audio.
